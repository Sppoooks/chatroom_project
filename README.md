# INTRODUCTION

Small project with the aim to learn the programming language C and networking.

# PURPOSE

A simple TCP chatroom where clients can communicate between each other via the terminal.

# FEATURES

The chatroom should allow users to chat with a username.
The chat history should be shown to users everytime they login.
Users should only be able to send text.

- Multiple client connections
- Chat history
- Text only
